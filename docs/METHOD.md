# 方法说明

本文档描述 KCT_Identification 流水线各步骤的方法细节与关键公式。

## 0. 总体思路

关键核心技术识别 = **技术关联网络 → 社区划分 → 候选筛选 → 赋权打分 → 阈值筛选**。
核心思想：在技术共现网络中找出既处于结构关键位置、又具备高影响力的技术主题。

## 1. 数据清洗（01）

- 合并多个年度 xlsx，统一字段；
- IPC 清洗：按 `^[A-H]\d{2}[A-Z]` 提取 IPC 小类（四字符，如 `B60L`）；
- 同族内优先取 DWPI 标引 IPC；
- 年份过滤 2003–2025；
- 缺失值：引用次数 → 0，权利要求数 → 中位数，同族规模 → 1。

## 2. 指标构建（02）

12 项指标，分 3 个维度：

| 维度 | 指标数 | 说明 |
|------|--------|------|
| 技术性 | 4 | 技术影响力类 |
| 经济性 | 4 | 经济价值性类 |
| 战略性 | 4 | 战略重要性类 |

（指标名称与量化字段对照见论文 Table 1。）

## 3. 热点技术识别（03）

对每件专利，其若干 IPC 各获得 `1 / (该专利 IPC 数)` 的权重；
累加全市所有专利，得每个 IPC 的加权频次；保留加权频次 ≥ 1 的 IPC 为高频技术。

## 4. 技术关联网络（04）

**Jaccard 共现系数**：

```
J(i,j) = c_ij / (c_i + c_j − c_ij)
```

其中 `c_ij` 为 i、j 共现专利数，`c_i`、`c_j` 为各自出现专利数。
取 P90 分位数为边阈值，高于阈值的边保留。

> 相对原方法的 Matrix Profile 相似度，Jaccard 更稳定且无需滑窗对齐。

## 5. 社区划分（05）

- **Leiden 算法**（`RBConfigurationVertexPartition`，seed=42）划分社区；
- **结构洞得分**（Burt）：

  ```
  sh = 0.5 × betweenness_centrality + 0.5 × (1 − constraint)
  ```

- 同时计算度中心度（degree centrality）。

> 相对原 Louvain 算法，Leiden 社区质量更优。

## 6. 候选筛选（06）

双维度取并集：

```
候选 = 结构洞得分前 5%  ∪  度中心度前 5%
```

剔除规模过小的社区（成员数 < 5）。

## 7. 赋权与打分（07）

**熵权法**：

```
E_j = −k Σ_i p_ij ln p_ij ,   k = 1/ln(n)
w_j^熵 = (1 − E_j) / Σ_j (1 − E_j)
```

**CRITIC 法**（相关系数取绝对值）：

```
C_j = σ_j × Σ_i (1 − r_ij)
w_j^CRITIC = C_j / Σ_j C_j
```

**加法组合**：

```
w_j = (w_j^熵 + w_j^CRITIC) / Σ_j (w_j^熵 + w_j^CRITIC)
```

对每件专利按 12 项指标加权求和得综合得分（**逐专利**，非 IPC 均值）。

## 8. 关键核心技术识别（08）

- 取全体专利综合得分的**前 25%** 为高分线；
- 按 IPC 统计高分专利数；
- 高分专利数 ≥ 全体均值（论文中为 2,271）的 IPC 入选；
- 合并语义相近的 IPC，得最终关键技术清单。

## 9. 稳健性检验（09）

- **赋权方法对比**：加法组合 / 纯熵权 / 纯 CRITIC，检验 Top 结果是否一致；
- **阈值方案对比**：不同高分分位数下结果的稳定性。

## 方法出处

- 本项目在 Jaccard 关联、Leiden 划分、逐专利打分三处做了改进
